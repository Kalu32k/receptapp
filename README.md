# ReceptApp

En mobilapp för att lagra, söka och dela recept.

## Funktioner

- ✅ Lägg till och redigera recept
- ✅ Sök efter recept
- ✅ Favoritmarkering
- ✅ Ingredienslista
- ✅ Matlagningsinstruktioner
- ✅ Dela recept
- ✅ Betygsättning och recensioner

## Teknik

- React Native + TypeScript
- Expo
- React Navigation
- Zustand (State Management)
- Axios (API)

## Installation

```bash
npm install
```

## Starta appen

```bash
npm start
```

- **Android**: `npm run android`
- **iOS**: `npm run ios`
- **Web**: `npm run web`

## Projekt struktur

```
src/
├── screens/        # App skärmar
├── components/     # Återanvändbar komponenter
├── services/       # API och data tjänster
├── store/         # Global state (Zustand)
├── types/         # TypeScript typer
└── utils/         # Hjälpfunktioner
```
